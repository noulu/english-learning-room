# 英语学习室

安装入口：https://noulu.github.io/english-learning-room/

## iPhone 安装

1. 在 Safari 打开安装网址，选择“分享 → 添加到主屏幕”。
2. 从主屏幕图标打开，点击“下载英语学习包”，等待全部完成。
3. 以后从图标进入，下载完成后可以断网学习。

首次访问、下载和更新需要网络。朋友不需要 GitHub 账号。中国大陆网络和真实 iPhone 的安装效果需要实际验证。

## 电脑使用

在 Edge 或 Chrome 打开安装网址并下载教材，之后用同一个浏览器进入。
Windows 也可使用另外提供的便携 ZIP：完整解压后双击启动器，教材和音频全部来自本机。

## 学习数据

进度、草稿和私人录音保存在各自设备上，手机和电脑不自动同步。在“设置与内容”中导出备份，换设备时可导入；导入会替换目标设备的英语存档。

课程包含1000教学词、72个独立测量词、45条输入句子和45条输出素材，以及全部对应音频。参考答案不是唯一正确答案；词汇估计是自评粗估。

此仓库只有公开英语发布包和发布配置。教材、音频、调度器来源及许可随发布包的 `licenses/` 提供；不包含开发者的私人学习存档或录音。
